# *Pomodoki - A focus timer for students*
---

## 1. Project Description
Pomodoki is a focus timer web application designed to help users [students] stay focused, manage their time,
and organise their study or work sessions.It provides a simple interface with a timer, different timer modes,
and additional panels for personalising the experience.

## 2. Features
- Focus Timer: A countdown timer for focused work or study sessions.
- Timer Modes: Switch between Focus, Short Break, and Long Break.
- Timer Controls: Start and reset timer.
- Soundscapes: Different focus sounds for you to choose.
- Themes: Access a panel for changing the visual theme.
- Task Management: Access a panel for managing tasks.
- Stats board: Access a panel for viewing productivity statistics.
- Settings: Open the timer settings.

## 5. How to use: 
1. Open Pomodoki in your web browser.
2. Select Focus, Short Break, or Long Break.
3. Click the Start button to begin the timer.
4. Use the Reset button to reset the timer.
5. Open Settings to access timer settings.
6. Use the floating navigation dock to access Sounds, Themes, Tasks, and Stats.
